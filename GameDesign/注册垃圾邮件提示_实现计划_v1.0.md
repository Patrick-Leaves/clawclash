# 注册页垃圾邮件提示 · 实现计划 v1.0

> **给执行者：** 本计划的每一步都用复选框 `- [ ]` 标记，请按顺序执行。规格见 [注册垃圾邮件提示_Spec_v1.0.md](注册垃圾邮件提示_Spec_v1.0.md)。

**目标：** 在注册弹窗的第二步界面加一行提示，告知用户「收不到验证码时去垃圾邮件文件夹找，并标记为非垃圾邮件」。

**做法：** 纯 HTML 静态文案，复用站内既有 `.hint` 样式类。挂在 `#authVerify` 面板内部，显示/隐藏由既有的 `showAuthPanel()` 管理——**不新增任何 JavaScript 逻辑、状态或事件监听**。

**技术栈：** 零第三方依赖；原生 Node `node --test` 测试；无框架 MPA 前端（经典 `<script>` + 服务器组装 HTML 片段）。

## 全局约束

以下取自规格，每个任务都隐含遵守：

- **文案逐字固定**为：`没收到？请到「垃圾邮件」文件夹找找，并把它标记为「非垃圾邮件」`
- 复用 `.hint` 工具类（`public/style.css:327`）；**禁止使用 `.warn-box`**（警告样式会让用户误以为发送失败）
- **禁止显示发件人邮箱地址**（运营方使用个人邮箱，公开等于泄露）
- **不新增 JavaScript**：不改 `public/platform.js`，不加事件监听，不加状态
- 不引入任何第三方依赖
- 提示必须位于 `#authVerify` 面板内，**不得**出现在 `#authRegister`（第一步）面板内

- [ ] **Step 1: 写失败的测试**

在 `test/registration-ui.test.js` **文件末尾**追加以下测试。

注意：该文件的 `harness()` 假 DOM **只解析元素的 `id` / `class` / `disabled` 属性，不解析文字内容**（见文件开头 `node()` 与 `html.matchAll` 循环），因此断言文案必须直接读取 HTML 片段文件，不能走 `h.node(...).textContent`。

```js
test('注册第二步面板包含垃圾邮件提示，且第一步面板不含', () => {
  const html = fs.readFileSync(path.join(__dirname, '../public/fragments/shared_modals.html'), 'utf8');
  const start = html.indexOf('id="authRegister"');
  const mid = html.indexOf('id="authVerify"');
  const end = html.indexOf('id="authLogin"');
  assert.ok(start >= 0 && mid > start && end > mid, '弹窗面板标记顺序应为 authRegister → authVerify → authLogin');

  const registerPanel = html.slice(start, mid);
  const verifyPanel = html.slice(mid, end);

  assert.match(verifyPanel, /verifySpamHint/, '第二步面板应有 id 为 verifySpamHint 的提示元素');
  assert.match(verifyPanel, /垃圾邮件/, '第二步面板的提示应提到「垃圾邮件」');
  assert.match(verifyPanel, /非垃圾邮件/, '第二步面板的提示应给出「标记为非垃圾邮件」的动作');
  assert.doesNotMatch(registerPanel, /垃圾邮件/, '第一步面板不应出现该提示');
});
```

- [ ] **Step 3: 实现——插入提示元素**

在 `public/fragments/shared_modals.html` 中找到 `#authVerify` 面板里的这一行：

```html
      <div class="verification-meta"><span id="codeExpiryText"></span><span id="resendWaitText"></span></div>
```

在它**下面**、`<button class="primary block" id="verifyCodeBtn" disabled>验证并注册</button>` 的**上面**，插入一行：

```html
      <p class="hint" id="verifySpamHint"><span>💡</span><span>没收到？请到「垃圾邮件」文件夹找找，并把它标记为「非垃圾邮件」</span></p>
```

插入后该区域的完整形态（用于核对缩进与上下文）：

```html
      <div class="verification-meta"><span id="codeExpiryText"></span><span id="resendWaitText"></span></div>
      <p class="hint" id="verifySpamHint"><span>💡</span><span>没收到？请到「垃圾邮件」文件夹找找，并把它标记为「非垃圾邮件」</span></p>
      <button class="primary block" id="verifyCodeBtn" disabled>验证并注册</button>
```

文案外层用两个 `<span>` 包裹是有意的：`.hint` 是 `display:flex`，裸文本会变成匿名 flex item，折行行为在各浏览器下不一致。
