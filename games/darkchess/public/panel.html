    规则速览 ▾
    • 4×8 棋盘共 32 格，中国象棋全套棋子背面朝上随机摆放；双方按顺序各翻一格，翻到不同颜色即分出谁执黑、谁执红。
    • 基础吃子：移动到对方已翻开棋子处即吃子，大吃小；等级相同同归于尽；卒/兵可吃帅/将（特例），但帅/将不能吃卒/兵。
    • 炮：不能靠移动吃子，只能隔一子（明暗不限）吃任意棋子，含对方帅/将与炮；吃暗棋当场公示身份。
    • 终局：一方棋子被吃光判负；双方连续停一手或连续 40 回合无吃子，按剩余棋子价值总和判定胜负，价值相等判和。

    玩法要点

    • 中国象棋全套棋子（黑红各 16 颗），4×8 棋盘共 32 格，背面朝上随机摆放。所有棋子只能沿横竖走一格，不沿用传统象棋走法与九宫/河界限制。
    • 翻棋定序：归属未定时双方按序各翻一格，颜色不同则分出谁执黑谁执红，相同则继续下一轮。
    • 行棋阶段：每回合三选一——翻棋 / 移动 / 吃子。无棋可走时引擎自动为你停一手。
    • 吃子：等级顺序 将/帅>士/仕>象/相>車>馬>炮>卒/兵，大吃小，等级相同同归于尽，卒/兵可吃帅/将（特例，帅/将不能反吃）。炮只能隔一子吃任意棋子（含暗棋，吃后公示身份），炮吃炮不同归于尽。
    • 终局：吃光判负；双方连续停一手或连续 40 回合无吃子，按子力价值总和（将/帅7、士/仕6、象/相5、車4、馬3、炮2、卒/兵1）判定胜负，价值相等才判和。

    代码契约

    module.exports = function onTurn(me, opponent, game) {
  // me/opponent: { side, remaining, capturedCount, revealedPieces:[[x,y],...] }（归属未定时均为 null）
  // game: { phase, board, turnNumber, noCaptureCount, legalActions, history, random, rules }
  return game.legalActions[0];
  // 翻棋 { action:'flip', at:[x,y] }；移动/吃子 { action:'move', from:[x,y], to:[x,y] }
};
    • 棋盘 game.board[x][y]：x∈[0,7] 横向、y∈[0,3] 纵向，左下角 [0,0]。空格为 null；暗棋为 {hidden:true}；已翻开为 {hidden:false,side,kind,power,label}。
    • 本游戏不设思考点配额，只有挂钟超时（数秒级）；返回非法动作判 illegal，抛异常/超时判 error/runtime，均当场判负。对局非确定性：每场使用全新随机种子（决定开局摆放与先手方）。

    烟雾测试 / 正式挑战与段位分

    • 提交后与三名训练棋手（随手/贪吃/推演）各座位各 1 局，共 6 局，固定种子；只挡崩溃不挡输棋。
    • 单场制，一场定胜负。段位分/反刷分规则与平台其它游戏一致，详见 Markdown 版指南。
