## 二、HTTP 基建与静态资源

- [ ] **PF-HTTP-01**【P1·手动】路由匹配：字符串路由精确匹配（带 query 仍命中，如 `/api/games?x=1`）；正则路由捕获组正确传参；未匹配的 GET 落静态服务；未匹配的 POST → 404。
- [ ] **PF-HTTP-02**【P1·手动】请求体上限：POST body > 2MB → 413 `{ok:false,error:'请求体过大'}`，连接被销毁。

- [ ] **PF-HTTP-06**【P0·手动】handler 抛异常 → 该请求 500 JSON，进程不退出、后续请求正常。
- [ ] **PF-HTTP-07**【P1·手动】进程级兜底：`unhandledRejection` / `uncaughtException` 仅记 `console.error`，服务继续响应（可用一次性调试路由或 REPL 注入验证）。
- [ ] **PF-HTTP-08**【P2·手动】长连接配置：`server.keepAliveTimeout=65000`、`headersTimeout=66000`（大于 Nginx upstream 60s；代码检视即可）。

- [ ] **PF-STAT-02**【P0·手动】路径穿越：`GET /..%2f..%2fdb.js`、`/%2e%2e/server.js` 等 → 403 或 404，绝不返回 `public/` 之外的文件内容。
- [ ] **PF-STAT-03**【P1·手动】协商缓存：html/js/css 响应 `Cache-Control: no-cache` + ETag；带 `If-None-Match` 复请求 → 304 无 body；文件内容改动后 ETag 变化 → 200 新内容。

## 三、账号体系

### 注册 `POST /api/account/register`（第 1 步：发验证码，不建号）

- [ ] **PF-REG-01**【P0·自动】两步注册主链路：请求须带 `registrationProtocol:'email-code-v1'`；register → 200 `{ok,registrationId,emailMasked,expiresInSec,resendAfterSec}`，**不含 Cookie、不建 accounts**；verify-code → 201 `{accountId,nickname,emailVerified:true}` + `Set-Cookie: sx_session=…`，pending 原子删除 —— `test/registration-api.test.js`、`test/api.e2e.test.js`。
- [ ] **PF-REG-02**【P1·自动】先校验 JSON 对象和字段类型；昵称/邮箱/密码缺失或类型错误 → 400 `invalid_input`，不得 500、哈希或发信 —— `test/registration.test.js`、`test/registration-api.test.js`。
- [ ] **PF-REG-03**【P1·自动】邮箱格式非法（非 ASCII、无 @/域名点、空 label、头尾连字符、CRLF、超长）→ 400；合法地址按 trim + 整体小写作为键 —— `test/registration.test.js`。
- [ ] **PF-REG-04**【P1·自动】密码长度 <8 或 >256 → 400 `invalid_input` + `field:'password'`；密码内容本身不 trim —— `test/registration.test.js`。
- [ ] **PF-REG-05**【P0·自动】昵称冲突 → 409 `{reason:'conflict',field:'nickname'}`；邮箱冲突 → 409 `field:'email'`；邮箱大小写同键但不错误合并点号/加号别名 —— `test/registration.test.js`、`test/registration-api.test.js`。
- [ ] **PF-REG-06**【P1·手动】频控：同 IP 10 分钟内第 6 次注册 → 429 + `Retry-After` 头 + 文案含剩余秒数。
- [ ] **PF-REG-07**【P0·自动】同邮箱新 register 在冷却后是明确的新轮次；只有新邮件成功才替换资料/码/registrationId 并把 attempts 归零。发送失败不覆盖旧 pending；掩码形如 `p***@qq.com` —— `test/registration.test.js`。
- [ ] **PF-REG-08**【P1·自动】SMTP 明确失败 → 502 `mail_failed`：首次发送不新增 pending，失败重发保留旧码/ID/attempts/期限，失败不扣正式额度或启动冷却；真实模式响应不回验证码 —— `test/registration.test.js`、`test/mail.test.js`。
- [ ] **PF-REG-09**【P2·自动】密码与验证码只以随机盐 scrypt 哈希存储，验证码前导零保留；接口结果不含哈希 —— `test/registration.test.js`。
